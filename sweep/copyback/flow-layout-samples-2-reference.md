## №4 — свёрнутый граф LongitudinalVector&W (секции-комментарии «D» и «Blocking»)

- Комментарии: «D» (5760, 224, 1744×672), «Blocking» (7600, 336, 1760×592). Между секциями ~100 px.
- Вход: knot (5792, 592) → Set Omega_free (6496, 576).
- Секция D: Set → Sequence_7 (6704, 560) → Branch (6880, 560) → Sequence_6 (7072, 400) → **столбец Set'ов** (7264, 416) / (7248, 512) / (7248, 608), шаг 96.
  Branch.else → Set (7248, 608) — в том же столбце, ниже.
- Деревья чистых — слева от своего Set, листья-Get'ы столбиком шаг ≈ 48, колонки ≈ 160.
- Get переменной **дублируется** у каждого потребителя (Omega_free — 4 раза).
- Exec-шина между секциями: Sequence_7.then_1 → knot (7024, 800) → knot (7392, 800) → knot (7632, 800) → Sequence_5 (7808, 768)
  — по низу секции, Y = низ + ~128.
- Выход: Sequence_5.then_1 → knot (9312, 832) → Tunnel (9408, 800).
- Узел с пузырём-комментарием (Set ParkingAnchor) — пузырь не мешает раскладке, отступ над нодой оставлен.

## Сводка новых правил (вдобавок к sphere-flow-layout-reference.md)

7. Плотный ряд: промежуток между exec-нодами 16–64, если между ними нет чистых входов.
8. Выход Completed цикла / else-ветка — под следующей нодой ряда, прямым проводом.
9. Чистые входы — снизу по умолчанию, сверху, если снизу ветки. Листья — столбиком шаг 48.
10. Get переменной — копия у каждого потребителя (не шина). Шина — только от выхода ноды.
11. Sequence → столбец исполнителей, шаг 96; деревья — слева от каждого.
12. Секции в комментариях, exec-переход между секциями — knot'ами по низу.
