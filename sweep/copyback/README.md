# sweep/copyback — эталоны из движка

Каждый файл — дословный Ctrl+C из UE 5.8 (copy-back пользователя). Это **единственные настоящие референсы** в репозитории:
всё остальное в `sweep/` — вывод наших генераторов (часть его подтверждена вставкой в движок, см. `docs/ENGINE_VERIFIED.md`).

- `tests/validate.test.mjs` прогоняет ВСЕ `*.txt` отсюда через `validateStrict(…, { fragment: 'auto' })` — валидатор не должен
  падать ни на одном настоящем копипасте; отдельные assert'ы сверяют с ними форму наших нод.
- `*-reference.md` — эталоны раскладки (ручные замеры пользователя в редакторе).
- Имена: `<тема>[-rNN].txt`, без суффикса `-copyback` (папка уже это говорит).
- Приватные дампы из проектов пользователя, которые он не отдаёт в тулкит, сюда не кладём.
