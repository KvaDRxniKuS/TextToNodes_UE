## Новое правило 13 — расстояние по слоям exec-пинов

Формулировка пользователя: «за каждый слой exec пинов расстояние до стенки следующих нод увеличивается
на 8 шагов (128 пкс)».

Расчёт в `src/flow-layout.js` (`flowExecGap`):

```text
N = количество видимых, несвёрнутых exec-выходов источника
зазор до следующей стенки = gap + max(0, N − 1) × execLayerGap
по умолчанию gap = 48, execLayerGap = 8 × GRID = 128
X следующего столбца = ceil16(X источника + flowWidth(источник) + зазор)
```

- Один выход — обычная плотная цепочка; каждый дополнительный слой добавляет 128 px.
- Прибавка одна на весь столбец: then_0 и остальные первые потребители имеют один X,
  а не получают последовательный сдвиг на 128 между собой.
- Считаются пины, а не число проводов: видимый неподключённый exec-выход тоже занимает слой.
  Exec-входы, data/delegate-пины, скрытые и свёрнутые advanced-пины прибавку не дают.
- Branch / макрос / Switch и вложенный Sequence используют то же правило, не только Sequence.
- Расширение зазора меняет только координаты, не добавляет knot'ы и не меняет связи.

Ручные координаты выше — пример **до применения новой общей формулы**, не точная калибровка её константы.
При пяти выходах формула добавляет 512 px к базовому зазору (итого 560), поэтому новая проба может
оказаться правее ручного примера. Визуальный verdict по этой новой прибавке ещё нужен.

## Следующая проба

`tools/gen-flow-demo-2.mjs` теперь создаёт пять выходов Sequence и три копии Self,
как в copy-back, но с правилом 13. Пузырям присваиваются реальные новые координаты,
генератор печатает состав каждого exec-ряда слева направо.

Координаты новой пробы: Event (0,0), Sequence (224,16); Set Location (944,0) → Print (1264,16);
Set Rotation (944,240), Print'ы then_2 (944,448), then_3 (944,608), then_4 (944,768).
Self для Set Location (224,240), Get Actor Location (224,288) со своим Self (80,288),
Self для Set Rotation (224,416).

Исправлено два соседних случая привязки дерева: высокая Sequence задаёт нижнюю границу старта
(её пересечение больше не трактуется как ветка, мешающая снизу); первый узел бокового ряда
наследует fork как предыдущую ноду для выравнивания значений. Self обоих Set теперь по X Sequence,
а высоты/зазоры чистых входов по-прежнему требуют дальнейшей сверки с ручным примером.
